This activity i more improve my css as you can see pls check in my index.css to see the difference i input the week3activity to week4activity2. Implementation of a Flexbox-based navigation bar instead of using a basic layout and the navigation was redesigned using Flexbox to properly align links horizontally and provide equal spacing. Use of properties such as display: flex, justify-content: center, and gap improved the visual layout, while flex-wrap: wrap ensures that the navigation remains usable even on smaller screens. To make the website responsive i add media queries and specifically targeting screen sizes below 600 pixels. When viewed on smaller devices the layout automatically adjusts: the navigation bar changes from horizontal to vertical, the container width expands to fit the screen, the image size is reduced, and the background color changes. These adjustments improve usability and readability on mobile devices, making the website more user-friendly.
